# 打印Anything（Chrome 扩展） v1.5

一个面向飞书 Canvas 与图片打印的轻量工具。支持多维表格滚动截屏、上传图片、粘贴图片以及**粘贴表格（数据转换）**，一键进入预览并打印或导出 PDF。

## 文件结构

```
base_print_v1.5/

├─ assets/
│  └─ icon.png                # 扩展图标

│  ├─ popup.html              # 弹窗 UI（多维表格、粘贴图片、粘贴表格、上传图片）

├─ background/
│  └─ background.js           # 后台页，负责视口截图与打开预览
├─ content/

│  └─ content.js              # 飞书 Canvas 滚动截屏核心逻辑
├─ preview/
│  ├─ preview.html            # 预览页结构与工具栏
│  ├─ preview.css             # 预览样式与打印优化
│  └─ preview.js              # 渲染、排版、PDF 导出等逻辑

```

## 快速使用

- **开发者模式加载目录**：在 Chrome 的扩展页面开启“开发者模式”，点击“加载已解压的扩展”，选择本项目根目录。
- **功能入口**：打开目标页面，点击扩展图标，弹窗内提供 4 个核心按钮：
  - `多维表格`：在当前页触发飞书 Canvas 滚动截屏，自动分段裁切并写入本地存储，随后打开预览。
  - `粘贴图片`：从系统剪贴板读取图片并进入预览（需用户交互触发）。
  - `粘贴表格`：打开一个新页面，可直接粘贴飞书多维表格数据，进行二次排版（分组、层级、调整列宽）后进入预览或保存。
  - `上传图片`：从本地选择图片（支持多张），按选择顺序写入预览。
- **预览操作**：在预览页可以设置标题、排版方向（纵/横）、缩放、边距与底部裁切；支持“去尾/恢复”、继续“追加图片”、直接打印或导出 PDF。

## 使用场景

- **飞书多维表格归档**：通过滚动截屏保存原始视觉效果，或通过“粘贴表格”提取纯数据进行精细排版。
- **内容整理**：将公众号文章、帮助文档、本地图片或剪贴板图片拼接为统一版式。
- **数据打印**：将复杂的数据表格转换为适合打印的 PDF 或图片格式。

## 功能特性

- **多维表格滚动截屏**：自动识别最大 Canvas，模拟滚轮与分段裁切，避免重复或丢帧。
- **粘贴表格（v1.5 强力推荐）**：
  - 支持飞书多维表格数据直接粘贴。
  - **智能分组**：支持多级字段分组统计。
  - **层级展现**：支持父子记录的缩进显示。
  - **自由调整**：拖拽调整列宽、删除不需要的列。
  - **完美转换**：一键转换为高清图片并进入打印流程。
- **图片来源多样**：支持本地上传与系统剪贴板粘贴。
- **预览排版可控**：标题、纵横向切换、缩放、边距、底部裁切与去尾/恢复。
- **导出支持**：调用浏览器打印；内置 jsPDF 导出高质量 PDF。

## 权限与兼容

- 权限：`activeTab`、`scripting`、`storage`、`clipboardRead`。
- 视口截图通过后台页执行，无需额外主机权限。
- 剪贴板读取需要在用户点击事件中触发，且浏览器需允许。
